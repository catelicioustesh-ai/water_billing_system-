## 🎓 EXAMPLE: HOW METER SENDS DATA

### Simple Python Script (Meter Device):
```python
import requests
import json

meter_number = "M12345"
api_key = "meter_xxxxxxxxxxxxx_1234567890"
current_reading = 15500

payload = {
    "meter_number": meter_number,
    "current_reading": current_reading,
    "api_key": api_key
}

response = requests.post(
    "http://server/Water_Billing_Project/auto_capture_reading.php",
    json=payload
)

if response.status_code == 200:
    print("✓ Reading sent successfully!")
else:
    print("✗ Error:", response.json())
```

## 🆘 TROUBLESHOOTING

### "API Key Invalid"
→ Regenerate key in Automated Meter Manager

### "Reading Rejected - Abnormal Consumption"
→ Consumption > 1000 units = manual review needed

### "Bills Not Generating"
→ Verify cron job scheduled correctly

### "500 Error from API"
→ Check database tables created properly

### "Connection Refused"
→ Verify auto_capture_reading.php path is correct
